# Hana ZMK Configuration

Standalone firmware configuration for the Hana split keyboard and its central dongle variants.

Migration source: `Sukumar002/zmk-keyboards` branch `zmk-dongle-oled-enhancements`, commit `126fc6be8c04d748e4f6d97152ede5f7007e9ea7`.

This repository is being established as the independent Hana firmware home. Firmware builds and hardware validation are required before treating the migrated state as a released version.
